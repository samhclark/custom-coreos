# Archived documentation instructions

Everything below this directory is historical evidence, not current system
documentation.

- Do not read this subtree during routine repository orientation.
- Do not infer current behavior from commands, paths, service topology, or
  pending actions recorded here.
- Never execute an archived command against the production NAS.
- Consult a historical file only when an active architecture document links
  to it for provenance or the user explicitly asks for migration history.
- Resolve any conflict in favor of `AGENTS.md`, `docs/README.md`, live
  `quadlets/`, `Containerfile`, and `overlay-root/`.

Preserve evidence when making unrelated changes. Do not update archived prose
merely to match the current implementation.
